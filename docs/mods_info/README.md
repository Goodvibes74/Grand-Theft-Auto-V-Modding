# Using the mods

Everything about using the installed mods in game: what each one does, how to open it, which keys and controller buttons it uses, and where those keys clash.

Installing, updating and removing mods is covered in the main [`README.md`](../../README.md) in the game root.

## Before you play

1. Launch with `PlayGTAV.bat`. It starts the game with BattlEye off, which every mod needs.
2. Single player only. **Never go online with these mods installed.** Your account will be banned.
3. If a mod doesn't respond, check the logs in the game root (`ScriptHookV.log`, `ScriptHookVDotNet.log`, `menyoolog.txt`).
